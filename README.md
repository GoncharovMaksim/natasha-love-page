# Natasha Love Page

Одностраничный сайт с таймером обратного отсчета (5 секунд), анимацией распускающегося цветка и посланием "Наташа, я люблю тебя".

## Стек технологий

- HTML5
- CSS3 (анимация лепестков, градиенты, адаптивная типографика Cormorant Garamond / Plus Jakarta Sans)
- Ванильный JavaScript (Canvas для парящих лепестков, логика таймера)

## Развертывание

Проект настроен для публикации на Vercel (`vercel.json`).
